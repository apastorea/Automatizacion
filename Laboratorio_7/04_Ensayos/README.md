# Estructura de captura por ensayo

Crear una carpeta `AAAA-MM-DD_tipo_observador_polos_ensayoN`. Guardar siempre las ondas físicas sin modificar, un CSV de UART y metadatos del diseño seleccionado. Marcar `valido_para_informe=true` solamente después de revisar saturaciones, señal, temporización y coherencia de escalas. Un `false` no significa borrar la captura: conservar diagnósticos identificados.
